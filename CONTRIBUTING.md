# Contributing to vibe-fence

Thanks for wanting to contribute.

## Getting started

1. Read `docs/PLAN.md` and `docs/research/synthesis/FINAL-v4.md` (locked Phase 1 decisions — M1–M4; 221 lines, 2026-10-21; supersedes `FINAL-v3.md` → `FINAL-v2.md` — prior versions retained).
2. Install dependencies: `bun install`
3. Make changes only in `src/` and `tools/` — `dist/` is generated.
4. Verify before opening a PR:
   - `bun run typecheck`
   - `bun run build`
   - `bun run validate`

## What not to do

- Do not edit `dist/` by hand — it is regenerated by `tools/generate.ts`.
- Do not skip `bun run validate` (checks `AGENTS.md` token budget, context budget, and freshness where applicable).
- Do not use "Turbo" in user-facing copy — name bands by guarantee (see FINAL-v4 §2 S-10; S-10 unchanged from v2).

## Pull requests

Keep PRs focused. Reference the relevant M1–M4 item from FINAL-v4 §4 where applicable.
