# Support

## Getting Help

- **Bugs / feature requests:** [GitHub Issues](https://github.com/poferraz/vibe-fence/issues) — use the Bug report or Feature request template.
- **Questions / ideas:** [GitHub Discussions](https://github.com/poferraz/vibe-fence/discussions) (Q&A) — or open an issue with label `question`.
- **Hackathon context:** Built for the **Meta Global AI Developer Hackathon** (Oct 26–Nov 4, 2026) — Indie track, *Build for Your World*. See `README.md` for judging alignment and `docs/PLAN.md` for roadmap.

## Response Time

Solo maintainer — best effort. Hackathon build window (through Nov 4) gets priority; post-hackathon follows weekday cadence.

## What to Include in a Report

- `vibe-fence` version (`npx vibe-fence --version` or `package.json` version)
- Runtime: `node -v`, `bun -v`, OS
- Reproduction steps + expected vs actual
- For guardrail reports: the prompt / file content that should have been flagged (redact secrets — use synthetic placeholders)
