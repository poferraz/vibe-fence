# Where Vibe Fence can act automatically

Evidence checked November 11, 2026. Companion to the [product direction](2026-11-11-product-direction.md).

**Offer persistent guidance wherever a host can load it, and claim prevention only at a boundary tested in that host.** A rule in an assistant’s context can suggest testing a change. A local checker can report what it inspected. A trusted hook can stop a supported action. These are three different promises.

## What the hosts document

| Surface | One-time setup and scope | Limit for Vibe Fence |
|---|---|---|
| Lovable | [Account settings → Personal instructions](https://docs.lovable.dev/features/knowledge#personal-instructions) works on all plans, without admin access, for every project the person opens in that workspace. Alternatively, a root `AGENTS.md` is read on every message. | A beginner can paste guidance without a terminal or GitHub connection. Lovable’s own [Quick scan](https://docs.lovable.dev/features/security#before-publishing) runs in the publish dialog; whether findings block publishing depends on workspace controls. Show how to interpret it. |
| Bolt / Replit / v0 | [Bolt Project Knowledge](https://support.bolt.new/settings/project-settings) applies within one project. [Replit Agent](https://docs.replit.com/features/project-setup/replit-dot-md) reads and may update root `replit.md`. [v0 instructions](https://v0.app/docs/instructions) apply once selected until unchecked. | Offer a copyable setup for the named surface. Preserve existing preferences. None of these instruction mechanisms establishes a Fence hook on Publish. |
| Codex | [Root-to-working-directory guidance](https://learn.chatgpt.com/docs/agent-configuration/agents-md) is collected once per run; `AGENTS.override.md` can supersede `AGENTS.md`. Start a new session after installation. | Non-managed [hooks](https://learn.chatgpt.com/docs/hooks) require trust. Errors or timeouts in a pre-tool hook can allow an action. |
| Claude Code / Cursor | [Claude Code](https://code.claude.com/docs/en/memory#agentsmd) can read `AGENTS.md` from v2.1.277; by default an applicable Claude instruction file takes precedence. An explicit `@AGENTS.md` import supports older or mixed setups. [Cursor](https://cursor.com/docs/rules) reads root and scoped nested files. | Claude distinguishes instructions from [blocking hooks](https://code.claude.com/docs/en/hooks-guide). Cursor’s agent rules [exclude Tab and Bugbot](https://cursor.com/help/customization/rules). |
| GitHub Copilot | VS Code Chat, CLI and cloud agent support `AGENTS.md`. Repository-wide `.github/copilot-instructions.md` reaches more surfaces, including GitHub.com Chat and Visual Studio Chat. [Support matrix](https://docs.github.com/en/copilot/reference/custom-instructions-support) | [Hook events and controls](https://docs.github.com/en/copilot/concepts/customizations/hooks) differ across CLI, cloud agent and VS Code. Name the surface; do not claim all Copilot sessions are protected. |
| Google | [Antigravity CLI](https://antigravity.google/docs/cli/best-practices/) reads root `AGENTS.md` or `GEMINI.md` at startup. [Individual free access moved there](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/) in June 2026. [Legacy Gemini CLI](https://geminicli.com/docs/cli/gemini-md/) defaults to `GEMINI.md` and supports imports or a configurable filename. | Google’s documented capabilities do not turn Fence’s current Antigravity guidance into an enforced check. |

## What the project can substantiate

The inspected working tree is `release/final` at `5189213` **with uncommitted changes**. Its [adapter list](../../README.md#supported-coding-agents) configures hooks for Claude Code, Cursor and Codex, a pre-tool plugin for OpenCode, and advisory guidance for Antigravity and Hermes. Its [evidence log](../EVIDENCE.md) records a synthetic Git commit blocked by the packed local checker, followed by a corrected commit that succeeded. It does not establish interception in those editors. Browser setup and Copilot coverage above describe possible distribution routes, not shipped, tested adapters.

One historical exception matters: [the v0.4.0 evidence log](https://github.com/poferraz/vibe-fence/blob/efc29b33775bd2cf5242f1952d08e1b08e6cc0b2/docs/EVIDENCE.md#november-4-muse-code-synthetic-host-rehearsal) records real Muse Code 1.4.14 sessions on local candidates. Fabricated unsafe writes and edits succeeded before installation and were denied in fresh trusted sessions afterward; a later rehearsal allowed removal of an unsafe line. This is evidence for those actions and versions. The separate Spark explanation call was not what blocked them.

For a new host, publish the version, trust state, harmless allowed action, synthetic blocked action and actual file outcome before claiming live protection. Otherwise report “guidance available” or “checks run at commit.” [Git hooks](https://git-scm.com/docs/githooks) can be bypassed and cannot intercept a browser’s Publish button. If a host cannot persist instructions, offer a per-chat paste and label it temporary. Fence can charge nothing and require no second key; the host’s own model usage and privacy terms still apply.
