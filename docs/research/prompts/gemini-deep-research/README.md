# Gemini Deep Research — vibe-fence (6 prompts)

> Each prompt is self-contained. Paste one at a time into the
> **Gemini web app → Deep Research** (Gemini Argon 4 High).
> They run outside the project root — no file references.
>
> After each run: copy the report → save as
> `docs/research/contributors/gemini-argon4-YYYY-MM-DD/NN-<slug>.md`
> → create/update `manifest.json` → log in `00-meta/LOG.md`.

## Which to run first?

Any order. But the logical sequence is 01 → 06 (harnesses → harness influence → elicitation → guardrails → companion UX → Meta models).

## After pasting a prompt

Gemini Deep Research will ask clarifying questions if your prompt is ambiguous — these prompts are written to minimize that, but if it asks, answer briefly and let it proceed. Each run takes 5–15 min. Don't batch multiple prompts in one run — one prompt = one report.
